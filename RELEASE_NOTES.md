# Автоматические обновления Banshee

- Добавлена автоматическая проверка новой версии при запуске и каждые 6 часов.
- Появилось окно с описанием изменений и прогрессом загрузки.
- Обновление устанавливается безопасно после проверки цифровой подписи.
- В настройках добавлена ручная проверка обновлений.
- Portable-сборка предлагает скачать новый архив без автоматической замены файлов.
