# Contributing

1. Створіть окрему гілку.
2. Не додавайте API-ключі, приватні відео або release-бінарники.
3. Запустіть `npm run check`, `npm test` і `cargo test --workspace`.
4. Оновіть `CHANGELOG.md` та `VERSION`, якщо змінюється поведінка для користувача.
5. Додайте короткий опис і сценарій перевірки до pull request.
